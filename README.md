# 🎵 Music Player  
A simple and responsive music player built with vanilla JavaScript.  
This project focuses on audio control logic, DOM updates, and interactive UI behavior while keeping the interface clean and intuitive.

[Live Demo](https://reyhanneh-gh.github.io/Espinas-Hotel/) 🪄

---

### ✨ Features  
- Play / Pause functionality  
- Previous / Next track navigation  
- Dynamic progress bar with click-to-seek  
- Auto-updated duration & current time  
- Repeat mode  
- Responsive layout using Tailwind  
- Uses a **local JSON API** for song data  

---

### 👩‍💻 About the Project  
This music player was developed as part of my practice in working with JavaScript's `<audio>` API.  
The project loads songs from a **local JSON file**, updates the UI dynamically, and provides core player controls like seeking, repeating, and switching tracks. The UI is designed with Tailwind CSS to ensure simplicity and responsiveness across devices.

---

### 🛠️ Tech Stack  
- HTML5  
- Tailwind CSS  
- JavaScript  
- Local JSON API
